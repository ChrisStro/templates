# OpenTunnel

Your agent's tool calls, on any machine.

OpenTunnel gives AI agents an ephemeral, end-to-end encrypted command tunnel to remote machines. No accounts, no standing access. Ctrl+C and it's gone.

## How to connect
```
curl -fsSL https://your.public.hostname/cli | sh -s -- create
```
